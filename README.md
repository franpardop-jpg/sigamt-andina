# SIGAMT - Manufacturas Andina S.A.
Sistema Integrado de Gestión de Activos, Mantención y Trabajadores (Ingeniería de Requisitos).

## Archivos del Proyecto
- `index.html`: Aplicación web responsiva (PC y móvil) con Triage de fallas, Catastro QR, Órdenes de Trabajo, Modo Offline y Panel IA.
- `database.sql`: Modelo relacional de base de datos con 8 tablas normalizadas y datos iniciales.
